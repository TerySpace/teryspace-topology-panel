# Changelog

## 1.0.0
- Initial release.
- Topology editor with nodes, links and bend points.
- Data mapping and thresholds for status and width.
- SVG rendering with zoom/pan and animations.
- Improved options editor with global theme/grid/zoom controls and icon pack management.
- Added bezier curve rendering mode for links.
- Added Docker and provisioning setup with preloaded sample dashboard and datasource.
